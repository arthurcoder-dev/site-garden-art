# 🛍️ Site da [Garden Club]

Site institucional/catalogo desenvolvido para a **[Garden Club]**, com foco em apresentar os produtos da marca e facilitar o contato com os clientes.

## 🌐 Acesse o site

**[gardenclub.com]**

## 📋 Sobre o projeto

Este projeto foi desenvolvido como um site comercial para a [Garden Art], apresentando seus produtos de forma organizada, moderna e responsiva.

O projeto foi desenvolvido utilizando apenas tecnologias front-end, mantendo uma estrutura simples e leve.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* Canva

## ✨ Funcionalidades

* Página inicial
* Catálogo de produtos
* Página About/Sobre
* Design responsivo
* Navegação entre páginas
* Integração com WhatsApp
* Links para contato

## 📱 Responsividade

O site foi desenvolvido para funcionar em diferentes tamanhos de tela:

* 💻 Computadores
* 📱 Celulares
* 📟 Tablets
